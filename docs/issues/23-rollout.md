# 23 全量推广与上线培训

Status: open
Type: task
Phase: Phase 3 — 知识库与自动化（第 11–14 周）
Blocked by: 11, 12, 18, 19, 20, 21, 22

## 背景

spec §5 Phase 3 出口条件：≥3 个高频业务场景完全自动化；机器人周活 > 60% 试点部门员工；故障/事故可复盘。全量推广（100–500 人）是平台从试点走向生产的分水岭，需要培训、SLA、运维就绪三线并行。

## 目标

平台面向全公司上线：培训完成、SLA 定义、运维面就绪（research-report §7 差距 #10：安装器/升级器/健康检查/监控大盘/错误上报）。

## 交付物

- [ ] 全量推广计划（分批上线、部门对接、沟通材料）
- [ ] 员工培训：使用指南、边界教育、安全红线（结合 MISSION 方法论）
- [ ] SLA 定义与监控大盘：可用性、延迟、错误率（基于 OTel）
- [ ] 运维面：健康检查、升级流程（锁版本策略落地）、错误上报、容量规划
- [ ] 事故复盘机制（SRE 标准）
- [ ] 遗留 backlog 清理与交接

## 验收标准

- [ ] M3 里程碑：IM 入口 + ≥3 场景自动化 + 定时任务上线
- [ ] 机器人周活 > 60% 试点部门员工（推广后复核）
- [ ] SLA 指标连续 4 周达标；事故均可复盘
- [ ] 运维手册交付，值班人员可独立处理
