# 销售部业务手册（示例）

## 客户分级

- A 级：年合同额 ≥ 100 万，配备专属客户经理
- B 级：年合同额 20–100 万，共享客户经理池
- C 级：年合同额 < 20 万，自助服务 + 在线支持

## 报价流程

1. 销售在 CRM 创建商机，填写需求摘要
2. 售前评估（2 个工作日内出方案）
3. 销售提交报价审批（>50 万需销售总监签字）
4. 客户确认后转合同流程

## 折扣权限

- 销售代表：最高 95 折
- 销售经理：最高 90 折
- 销售总监：最高 85 折
- 低于 85 折需 VP 审批

## 常见异议处理

- 「价格太高」→ 强调 ROI 与竞品对比案例（见 CRM 案例库）
- 「需要试用」→ 标准试用 14 天，可延长至 30 天（需经理审批）
