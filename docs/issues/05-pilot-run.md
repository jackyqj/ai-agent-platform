## 背景

spec §5 Phase 0 出口条件：种子用户完成 ≥1 个真实任务的端到端自动化；确定平台主用场景清单。试点是验证「DSH + 公司配置能服务真实任务」的试金石，产出直接决定 Phase 1 的优先级。

## 目标

5–10 名种子用户真实试用，收集任务样例与反馈，形成平台主用场景清单。试点构成已定（D19）：跨 2–3 部门（HR/行政 3 + 业务 3 + 研发/数据 2–4），首批 4 场景 = 制度/HR 问答、报销/财务流程、数据查询报表、研发文档检索。

## 交付物

- [ ] 种子用户名单与沟通机制（**从 HR/行政、业务、研发/数据 三个方向各推荐人选**，D19；Fog 待办）

- [ ] 真实任务样例集（每个任务标注：目标/工具/耗时/成功率，覆盖 4 个首批场景）
- [ ] 反馈记录与问题清单（按「目标不清/缺工具/缺权限」分类，对应 MISSION 方法论）
- [ ] 主用场景清单（Top 5–10，进入 Phase 2/3 排期）
