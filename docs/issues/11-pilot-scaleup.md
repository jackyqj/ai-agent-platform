# 11 试点扩量 30–50 人

Status: open
Type: task
Phase: Phase 1 — 多用户与身份（第 3–6 周）
Blocked by: 06, 07, 08, 09, 10

## 背景

spec §5 Phase 1 出口条件：50 名员工通过企业微信扫码登录，会话跨设备可恢复；管理员可看到每会话审计记录。这是多用户架构的第一次规模化验证。

## 目标

试点从 5–10 人扩到 30–50 人，验证多用户架构在真实负载下的稳定性。

## 交付物

- [ ] 试点扩量计划（部门选择、通知、培训材料）
- [ ] 稳定性监控：实例启动延迟、故障率、资源水位（配合 06/10）
- [ ] 用户反馈收集（复用 05 的反馈机制）
- [ ] 问题复盘与修复清单

## 验收标准

- [ ] M1 里程碑：50 人 SSO 登录可用，会话跨设备恢复，审计可见
- [ ] 实例平均启动延迟达标（建议 <10s，懒启动可接受预热）
- [ ] 试点期无阻断性故障；遗留问题全部进入 backlog
